
# YouTube Comments Analysis Using Big Data Analytics

## Project Description
This project analyzes YouTube comments using Python
and performs sentiment analysis.

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly
- VADER Sentiment Analysis

## Features
- Total Comments Count
- Positive Comments
- Negative Comments
- Neutral Comments
- Sentiment Analysis
- Data Visualization
- Download Analyzed CSV

## How to Run

1. Install Python.
2. Install required libraries:
   pip install -r requirements.txt
3. Run the project:
   streamlit run app.py

## Dataset
Sample YouTube comments CSV file.

## Output
Interactive dashboard showing sentiment analysis
and visualizations.
